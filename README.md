## 🚀 How to Test Locally in 30 Seconds

All 3 extensions work out-of-the-box in **Google Chrome**, **Microsoft Edge**, **Brave**, **Opera**, and other Chromium-based browsers:

1. Open your browser and visit:
   - Chrome: `chrome://extensions`
   - Edge: `edge://extensions`
2. Enable **Developer mode** (toggle located in top-right or left menu).
3. Click **Load unpacked** (or "Load unpacked extension").
4. Select one of the folders:
   - `extensions/1-quick-qr-scanner`
   - `extensions/2-tab-qr-generator`
   - `extensions/3-wifi-qr-creator`
5. Pin the extension to your browser toolbar and start testing!
